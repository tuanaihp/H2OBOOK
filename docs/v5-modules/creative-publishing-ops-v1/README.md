# H2OBOOK Creative Publishing Operations V1 Unified

Module nội bộ tách riêng khỏi Public Academy V5 và Academic Operations V1.

Một pipeline duy nhất cho 12 bề mặt:

`assets → ingestion → blocks → books → brand-kit → templates → design-library → clones → bulk-publishing → editor → content-health → publish`

Route preview:

`/creative-publishing-v1-preview/[surface]`

Module giữ nguyên `AppShell`, `useAppStore`, `useEditorStore`, Unified Input 4.13.7, Editor 4.12+, Supabase, R2 và publishing worker.
