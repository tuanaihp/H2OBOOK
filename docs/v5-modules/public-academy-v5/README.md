# H2OBOOK Public Academy V5 Unified

Module hợp nhất duy nhất cho toàn bộ bề mặt công khai và đăng nhập:

- Public Home V3 data flow + Journey Planner.
- About.
- Books.
- Courses.
- Learning Paths.
- Strategy Hub.
- Membership + enrollment + checkout bridge.
- Login Experience V2 + role redirect.
- Shared fallback/Supabase loader, analytics links và feature flags.

V5 thay thế hoàn toàn việc tích hợp riêng lẻ Public Home V3 và Public Academy V4.
Không tự chạy migration, không thêm dependency npm mới và không thay Auth/Payment contract hiện có.
