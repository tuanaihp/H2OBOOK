# H2OBOOK 4.13.6 — Unified Input Orchestrator

- Added one session/state machine for all supported input formats.
- Added common preview, destination selection, correction and commit UI at `/input`.
- Added idempotent `input_sessions` and `input_session_events` persistence.
- Added atomic semantic/design commit with optimistic document-version validation.
- Added append chapter, replace document and new book destinations.
- Added worker job linking, retry, cancellation, recovery and offline session cache.
- Added domain/analytics events and Realtime session publication.
- Aligned content-node database constraints with table row/cell semantic nodes.
- Added Phase 6 unit/runtime validators and moved roadmap to Phase 7.
