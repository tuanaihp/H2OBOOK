# H2OBOOK Global Neural Design System — Surface Matrix

| Surface | Routes | Intensity | Motion | Primary treatment |
|---|---|---:|---:|---|
| Public | `/`, `/academy/*` | Immersive | High but lightweight | Neural ambient, active AI story, editorial visual |
| Student | `/student/*` | Balanced | Medium | Learning intelligence, Skill Map, memory cues |
| Workspace | Dashboard, store, business routes | Subtle | Low | Glass topbar, intelligent accents, unified cards |
| Creative | Editor, design library, assets, templates | Focus | Minimal | Chrome only; never overlay canvas |
| Reader | `/reader/*`, `/embed/*` | Focus | Minimal | Progress and Smart Study cues only |
| Auth | Login/signup/auth | Immersive | Medium | Secure neural background, trust signal |
| Portal | `/portal/*` | Balanced | Low/medium | White-label academy intelligence |

## Non-negotiable rules

1. Neural visuals never own routing, auth, stores, database or business logic.
2. Editor canvas and reader page content remain visually untouched.
3. All movement stops under `prefers-reduced-motion`.
4. No Rive, Spline, Three.js, WebGL or AI API is required.
5. Public/Auth can be expressive; Workspace must stay operational and quiet.
6. One feature flag must support instant rollback.
