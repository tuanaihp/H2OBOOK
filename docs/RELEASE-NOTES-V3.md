# H2OBOOK V3 Release Notes

## Phiên bản 3.0.0

V3 được ghép trực tiếp vào V2, không thay thế hay tách repository.

### AI-assisted publishing
- Bảy chế độ trợ lý nội dung.
- Local engine để demo không cần API.
- Provider-agnostic AI Gateway route.
- Lịch sử AI job theo sách.

### Publishing governance
- Review board theo trạng thái.
- Checklist phát hành.
- Bình luận gắn review, page và element.
- Workflow yêu cầu sửa và phê duyệt.

### Collaboration
- Presence/session model.
- Danh sách người đang online và trang đang mở.
- Page lock data model.
- Comment resolution hub.

### Business expansion
- License agreement cho template.
- One-time, subscription và revenue-share.
- Clone limit, seat limit và royalty payout.
- White-label portal cho từng đối tác.

### Automation & quality
- Trigger/action automation rules.
- Manual test run và activity log.
- Content Health scan với điểm thành phần và cảnh báo.

### Data and API
- Backup version 3, tương thích nhập version 2.
- Migration Supabase V3 với RLS.
- `/api/v3/ai` và `/api/v3/manifest`.
